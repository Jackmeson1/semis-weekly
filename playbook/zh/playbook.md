# 远端序数规则手册（草稿 v0.2，2026-10-28）

本手册里的“作者”，指这套框架参考的一位宏观交易者，依据是其公开发表的观点。

模型每周出报告时要遵守的判断规则，整理自作者 2024 年到 2026 年的公开观点。数字由代码按 `signals/signals.yaml` 算好，模型只读结果、不自己算。

## 三级聚合

作者是分层、分期限判断的，所以报告也分三级，逐级往上聚合，不一次性把所有东西搅在一起。

| 级 | 做什么 | 读什么 | 规则文件 | 产出 |
|---|---|---|---|---|
| 1 信道 | 每个信道单独判定 | 只读本信道的信号 | `channels/C1`–`C7` | `logs/<周>/C1-credit.md` 等 7 份 |
| 2 期限 | 远、中、近各自汇总 | 只读第 1 级的日志 | `aggregation.md` 第 1 节 | `logs/<周>/near.md`、`mid.md`、`far.md` |
| 3 综合 | 处理跨期限冲突，给动作含义 | 只读第 2 级和 `invariants.md` | `aggregation.md` 第 2 节 | `logs/<周>/synthesis.md` |

- 每一级只读下一级的结论。第 3 级要引用某个信号时，必须同时引用解读它的那份信道日志。
- 某一级判断出错时，回到那一级的日志改，其他级重跑就行。
- 每个信道可以单独重跑。例如本周只想更新信用，就只跑 C1，再跑第 2、3 级。

每个信道文件的结构相同，同时当教材用：
1. **讲解**：这个信道在量什么、为什么会传导到半导体。这部分是研究时补充的，不是作者的观点。
2. **作者怎么看**：相关观点和规则（均为转述）。
3. **信号**：本信道用哪些信号、阈值依据。
4. **切换规则**：作者用过的触发条件。
5. **常见坑**。
6. **本周日志写什么**：固定字段。

## 信道日志格式

第 1 级每份日志都用这个骨架，写法按 `style.md`。最后的 json 块会被 `python -m semis ingest` 读进 `judgments` 表，字段名不能改。

````markdown
# C1 信用 · 2026-W44

**状态**：接近收紧
**一句话**：……

## 依据
| 指标 | 本周 | 对比 | 警戒线 | 状态 |
|---|---|---|---|---|
| 云厂资本开支占经营现金流 | 0.85 | 上季 0.77 | 0.8 留意，1.0 收紧 | 接近 |

表下一两句：这些数字说明什么，依据哪条规则（写规则的名字，比如“越依赖外部融资，信用越重要”）。

## 期限含义
- 中：……
- 远：……

## 和上周比
……

## 讲解
只讲一个概念，用本周的数字，150–250 字，分 2–3 段，最后一句说它怎么传到半导体。

## 偏离与不确定
……没有写“无”。

```json
{"level": 1, "scope": "C1", "state": "watch", "verdict": "一句话", "horizons": {"mid": "……", "far": "……"},
 "signal_refs": ["S-L3-03"], "rule_refs": ["INF-02"], "deviation": "", "confidence": "中", "model": "sonnet"}
```
````

- `state` 只能是 `slack` / `watch` / `binding` / `na`，页面上显示为 没收紧 / 接近 / 收紧 / 数据缺失。
- 信道的 `state` 由模型综合本信道的信号给出，通常取最严重的那个，但可以有理由地调低或调高，理由写进 `deviation`。
- `horizons` 只写本信道覆盖的期限（见 signals.yaml 的 channels）。
- 数字只能来自输入包，不能自己算新的数字。
- 信道文件里提到的 VETO、NOVETO、INF、ACT、CAL 编号，定义在 `aggregation.md` 第 2 节。第 1 级写日志时可以读那几张表作参考，但只引用和本信道有关的规则，不做跨信道的判断。
- 编号只写进 json 的 `signal_refs`、`rule_refs`。正文、表格和 json 里会显示在网页上的文字，都用 `glossary.yaml` 里的名字；`semis check` 会拒收写了编号的日志。

## 依据标签

- **明说**：作者明确写出。
- **推断**：从作者的论证或持仓统计推出。
- **补充**：不是作者的，是研究时加的。报告里引用这类规则要说明。

可以偏离规则，但必须在日志的“偏离”一栏写明偏离哪条、为什么。

作者的帖子是研究材料。手册以外的作者新帖不自动生效，要先人工确认再改手册。

## 层级编码

| 层 | 含义 |
|---|---|
| L0 | 长期结构：AI/token 需求、算力瓶颈、美债规模、地缘 |
| L1 | 宏观政策：长端利率、利率速度、联储路径、政策冲击 |
| L2 | 流动性管道：国债发行与拍卖、净流动性、TGA、逆回购 |
| L3 | 跨资产：信用利差、云厂融资、美元、日元、油 |
| L4 | 仓位与资金流：gamma、CTA、对冲基金杠杆、波动率 |
| L5 | 产业：云厂 capex、产能、存储周期、模型公司收入 |
| L6 | 公司：EPS、毛利、指引、估值 |
| L7 | 情绪叙事：泡沫论、FOMO |
