# 不变量

第 3 级综合时逐条体检，写“稳 / 受压 / 动摇”，并列出触发的威胁信号和对应的信道日志。

## INV-01 AI / token 需求不会到顶 · L0 · 明说

- 2024-06 作者认为牛市取决于投资回报，本质是技术革命与长期利率之间的博弈。
- 2025-11 作者判断，在 scaling laws 被明显证伪之前，capex 没有理由减速。
- 2026-07 改写：模型公司的 ARR 可能下降，但需求是 token 需求，不依赖某一家。
- 2026-10 再改：关键变成模型公司（labs）能否赚钱、手里有没有钱。
- **威胁信号**：C5 的 S-L5-03（云厂 capex 同比）跌破 watch；S-L5-01、S-L5-02 连续走弱；C1 的 S-L3-03 进入 binding（需求还在，但没钱接）。
- **不算威胁**：泡沫论、单季财报 miss、产品延期（aggregation.md 的 NOVETO-03、NOVETO-04）。

## INV-02 美债供给压长端，降息不等于长端下行 · L2/L1 · 明说

- 2024-05 作者把持续的大规模发债视为影响美元利率的最大且被低估的风险。
- 2025-01 作者提醒不要一看到降息就以为流动性会溢出，并表示自己对长债利率的判断一直没有变。
- 2026-09 改写：利率水平本身不是问题，也不是市场下跌的原因，要看的是波动。
- **用法**：联储降息本身不能推出“流动性改善”。看 C2 的速度和拍卖。

## INV-03 半导体是卖方计划经济，缺货看产能 · L5 · 明说

- 2026-01 作者称半导体是纯粹由供给方安排产能的行业：大厂一旦决定投产，需求旺、缺货的大方向就不会变，不必担心。
- 作者 2024 年的个股方法：从台积电 CoWoS 产能分配推 NVDA 出货和 EPS，信息差消失就卖。
- **用法**：选股看谁有产能、谁在瓶颈上；C5 的台积电月营收是第一手读数。

## INV-04 融资是最终约束 · L3 · 明说（2025 年底才出现）

- 2025-11 当时还不纳入判断，认为要等数据中心的资产证券化债券卖到养老金手里再说。
- 2026-07 升到最高：股价下跌可以扛，信用恶化不能。只要认为信用不会出现断崖式恶化，就可以坚定看多，缩表、战争都不改变这一点。
- 2026-07 认错：不能因为公司、行业层景气，就无视宏观资金面。
- **用法**：C1 是检查顺序的第一步。
